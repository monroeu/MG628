# MG628 Week 10 — Forecasting with Time Series Data Lab

Live URL after publishing: `https://monroeu.github.io/MG628/week10/`

This folder uses the shared `lab-engine/` already in the repository (added with Week 9). Nothing outside `week10/` changes.

## 1. Supabase (one time)

In the Monroe participation project's **SQL Editor**, run `week10/lab.sql`. It loads the lab's 50 slides and 36 graded questions under the lab id `forecasting`. (`lab-engine/schema.sql` was already run for Week 9; no need to run it again.)

## 2. Participation system (recommended)

Publish a Week 10 assignment for MG-628-159W in the Instructor Control Center with page path `week10/index.html`, so Week 10 shows as available on the home page and in the top navigation. To record active study time centrally, paste the assignment's ID into `participationAssignmentId` in `week10/lab-config.js`.

## 3. Publish with GitHub Desktop

1. Extract this package into `Documents\GitHub-Clean\MG628-Verified`, so `week10` sits beside `week09`.
2. In GitHub Desktop, check **Current branch** is **main**.
3. Commit with the summary `Add Week 10 forecasting lab`, then **Push origin**.

## 4. Check it

Open `https://monroeu.github.io/MG628/week10/`, sign in with a test Student ID, and watch one slide through to its last build.
