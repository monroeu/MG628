5. Dates, Boolean Logic & Filtering

Python can evaluate a business rule row by row. That produces Boolean values: True or False.

Convert text dates to real dates
df['Admission_Date'] = pd.to_datetime(df['Admission_Date'])
df['Discharge_Date'] = pd.to_datetime(df['Discharge_Date'])
Read it in English: Convert the two date columns from text-like CSV values into datetime values that Python can compare.
pd.to_datetime
Convert date-like values into pandas datetime values.
df['Admission_Date']
Select the Admission_Date column.
df['Discharge_Date']
Select the Discharge_Date column.
What you should expect: The date columns can now be compared chronologically.
Why a manager cares: Logical date checks catch records that may be impossible or operationally suspicious.
Create a Boolean validation flag
df['Date_Error'] = df['Discharge_Date'] < df['Admission_Date']
Read it in English: For every row, test whether discharge occurred before admission. Store the True/False result in a new column named Date_Error.
Date_Error
A new validation column.
<
A comparison operator meaning less than / earlier than.
True
The row violates the date rule.
False
The row passes the date rule.
What you should expect: P003 should be True; valid timelines should be False.
Why a manager cares: A validation flag preserves the questionable record for review instead of silently deleting it.
Filter to valid records
df_clean = df[df['Date_Error'] == False]
Read it in English: Keep only the rows where Date_Error is False and store them in a new DataFrame named df_clean.
df_clean
A separate cleaned/filtered DataFrame.
df['Date_Error'] == False
A Boolean mask selecting rows that pass the rule.
What you should expect: P003 is excluded from df_clean but still remains in the original df.
Why a manager cares: Keeping both original and filtered versions improves traceability and auditability.
Homework help

Use the validation column as evidence

Do not simply delete a suspicious record. First create a Boolean check, inspect which rows are True, and document why the row is being excluded or reviewed. In the healthcare exercise, P003 should be the row that fails the date rule.

10. Managerial Judgment, Reliability, Validity & Ethics

Python will do exactly what you instruct it to do. The computer cannot decide whether your cleaning rule is fair, clinically appropriate, legally defensible, or conceptually valid. That responsibility remains with people.

Missingness → Reliability

Deleting incomplete rows may systematically remove people with lower access, different language needs, or more complex circumstances.

Categories → Validity

Two labels that look similar may represent different concepts. Standardization must follow meaning, not appearance.

Outliers → Ethics

A rare observation may be an error, but it may also be a safety event, fraud signal, vulnerable group, or emerging need.

Documentation → Governance

Record what changed, why, by whom, using which rule, and how the output was validated.
